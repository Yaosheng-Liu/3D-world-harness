怎么使用

先看图 → 标记差异 → 写修改要求 → 发送。记录与本次反馈可分别展开；拖动输入框或反馈详情顶部的小横条调整高度，双击恢复默认。会话顶部「本次反馈」可展开查看保留的截图、视频时刻和额外引用；发送包含本轮所有保留证据，引用只是指出具体目标。提交成功后，聊天消息下方可以重新查看原图、标注图和叠图对比。

底部半透明会话框可点「收起会话」隐藏；标注完成后点右下角「展开会话」继续输入，草稿和标记会保留。聊天记录位于输入框上方，可独立收起；有新消息时入口会显示数量，查看旧消息时可点「回到最新」。按 Ctrl / ⌘ Enter 发送。

对照模式左边是参考图，右边是当前 3D 场景。左上角图标打开工作台侧栏，可切换／新建场景、调整布局与日夜模式、查看任务、执行记录和帮助；子页面通过「返回场景」回到场景列表。点击侧栏外或按 Esc 收起，输入内容和滚动位置保留。参考区只显示图片信息，无参考图时可点「选择图片」；视频与帧序列由插件送入。图片底部提供缩放与适合窗口，悬停图片显示标注工具。图片引用统一放在会话输入框左下角「＋」：可引用当前参考图／视频帧、当前场景画面／截图，或从已保存截图中选择；引用旧图保留其视角、标记和叠图，不跳转当前画面。正文用【图片1】【标记1】【物体1】等分类编号引用，完整来源放在输入框内的卡片详情。同名的不同来源会加编号区分；图片卡片可预览，其他卡片可查看完整名称，× 只移除引用。删除短名称会整处删除，可撤销恢复。鼠标移入参考图片自动显示参考标注工具，移到工具栏继续操作时保持显示，离开图片与工具栏后收回；触屏轻点图片或键盘聚焦图片也可打开。鼠标移入右侧实时 3D 或截图的有效画面会显示场景工具，移到工具栏可继续操作，离开画面与工具栏后收回并保留已选工具；触屏轻点或键盘聚焦画面也可打开，进入截图时自动展开截图工具；仅打开面板、选择工具或打开参考浮窗不会生成截图。参考与场景分别记住工具：在参考图画点或擦除时，右侧实时 3D 仍可正常旋转。浮栏跟随当前操作的图片，可单独收起；常用工具包括选择、点、框、线和橡皮擦，「更多」里是箭头、文字、自由画笔和对应编号。也可用 1–8 切换工具。拖动会话标题栏空白可移动磨砂窗口，位置按会话和布局记住；聚焦标题栏后用方向键微调，Shift 加速，Home 或双击空白恢复默认位置。顶部细条仍用于调整高度。会话收起时，Codex 正在处理会显示转圈状态；会话从右下角入口平滑展开，收起时缩回入口，保留草稿、滚动位置和自定义高度；系统开启减少动态效果时直接切换。左右拖动中间分隔线可调整参考图与场景宽度，双击恢复均分；窄屏仍上下排列。3D／截图预览条放在右图下方，卡片紧凑显示，悬停或键盘聚焦时平滑展开；对照模式左右画布保持同高，视频与关键点控件变化时仍对齐。沉浸模式预览条悬浮在底部，会话避让预览条。场景顶部直接点「物体 / 部件」切换按钮，决定在 GLB 中点击整件物体还是具体节点；参考图可滚轮缩放，按住空格拖拽平移。实时 3D 中选择「选择」时可拖动旋转场景、右键平移、滚轮缩放，并点选物体或部件。

选择带相机位姿的参考图时，场景会切到对应拍摄机位。场景顶部「叠图」菜单统一提供叠加开关、透明度、常用档位和「对齐」。手动旋转后，可在这里重新对齐；将透明度调为 0% 也可隐藏叠图。截图或开始标记时会保留当时的叠图参考与位置；标记画在叠图上方，仍可调整本张截图的透明度或开关。每张截图的设置独立保存，切换左侧参考图不会替换旧截图的叠图。发送时附带带标记的叠图对比、干净场景截图、参考原图及叠图参数。旧截图未保存叠图信息时，请回到 3D 新增截图。没有相机位姿的图片仍可手动对照。点击参考缩略图可切换对应的视频机位，拖动进度条继续使用该机位；未匹配参考图的机位使用首帧缩略图作为入口。

点、框、线和箭头直接显示在标注工具栏，「更多」提供自由画笔、文字与对应编号。实时 3D 中同样可使用这些工具；首次真正点击或拖动画图时，系统自动保存当时的截图、相机、选中对象与版本，并在该截图上完成标注，随提示一起发送。仅打开面板或选择工具不会生成空截图。已固定截图上的后续笔画留在同一张图；返回实时 3D 后再次开始绘制会保存新截图，即使没有移动相机，旧图和标记仍保留。右图下方用同一排预览卡片切换视图：第一格「3D」始终保留，用于旋转、缩放和点选物体；后面的截图按创建顺序排列，点击任意截图即可查看并标注，高亮卡片表示当前画面。右侧工具栏直接调整透明度与地面方向，「对齐」恢复参考拍摄机位；双击物体或按 F 聚焦。选择「选择」工具可在截图中点击标记，按 Backspace 或 Delete 删除选中的标记；拖动到会话框即可引用，收起的会话会自动展开。标记按类型获得稳定名称，例如点1、点2，删除或撤销不会让其他标记改名。截图的标注浮栏中可点「隐藏名称 / 显示名称」切换文字标签，偏好刷新后保留；标记本身、文字注释、列表引用与发送的反馈名称保留。返回实时 3D 请点击卡片栏第一格；截图和标记保留；调整实时 3D 视角后再次绘图会自动保存新图，旧图和标记继续保留。也可点击「截图」主动保存当前视角，最多保留 8 张静态截图。点击右图下方的截图卡片，选择任意旧图继续标注。删除某张只移除它和自己的标记，可撤销。没有截图时卡片栏仍保留实时 3D 入口；多张截图可横向滚动。转动实时 3D 视角不会覆盖它，发送时会附带所有保留截图、各自标记及相机视角。

「橡皮擦」（快捷键 8）可点击或拖动擦除整条标记，松手生效；一次拖动可以擦多条，撤销一次会一起恢复。拖动中按 Esc 可取消。只擦当前参考图或所选截图中可见的标记，不修改原图；在实时 3D 中请先选择已保存的截图。橡皮擦使用固定大小，圆形光标表示擦除范围；截图栏和左右比例会记住。方框内部的空白不会触发擦除；线段、箭头、文字、点和自由笔迹都可擦。

标注浮栏「清除本图」只清除当前参考图或当前截图上的标记，保留图片与其他标记；顶栏「⋯ → 清空本轮图片与标记」才会移除整轮截图、时刻和标记。两者都会显示具体范围和数量，确认后执行；点击「取消」或按 Esc 保留内容，「撤销 / 重做」可回退或恢复新增、删除及清空标记；快捷键为 Ctrl / ⌘ Z 和 Ctrl / ⌘ Shift Z，也可用 Ctrl Y 重做。输入框保留文字自己的撤销。历史只保留在当前页面，刷新后重新开始；已发送的反馈不会改变。

标记可以只出现在参考图上。需要表示两边对应时，给标记选择同一个编号即可。在底部写一段完整提示，点击对象、选中节点或标记旁的「引用」把它插入光标处；一段话可以引用多个目标。点击场景工具栏的「清单」（旁边显示标记数量），再点「引用全部标记」即可一次插入全部标记，已有引用会跳过。动态标记的机位、帧号和时间保留在引用详情与反馈中，正文只显示标记短名称；第一帧从 1 开始编号。可在左侧栏的任务入口选择另一条 Codex 任务，或选择模型新建任务；切换后新反馈进入新任务，已提交反馈仍留在原任务。新任务不会继承旧对话。使用普通 MCP 模式时，反馈先保存，待 MCP 工具读取后交回 Codex。使用 MCP 事件模式时，反馈会保存在工作台；插件订阅后可接收视觉反馈事件。本页面不创建或切换 Codex 任务，订阅状态可在「侧栏 → 执行记录」中查看。

静态截图与视频保留时刻统一接在实时 3D 卡片后，按创建顺序排列并使用场景截图封面。封面默认 112×63，鼠标悬停或键盘焦点可见时在原位平滑展开为 160×90，尊重系统减少动态效果设置；触屏保持紧凑尺寸，可直接点击。卡片显示稳定截图名称；带时间的截图仅显示精确到毫秒的单个时间戳，例如 00:09.900，不附时间区间。悬停或键盘聚焦卡片不会打开悬浮预览弹窗。进度条下方的小刻度定位当前机位已保存的截图，同一时刻有多个视角时，点击刻度可打开选择列表。点击视频卡片会暂停并恢复保存的机位与时间；之后播放、逐帧或拖动视频只浏览参考，右侧固定截图与原标记保持不变，点击「3D」才返回实时场景。标注另一参考帧会保留该时刻的证据，不覆盖右侧正在查看的旧图。静态截图和动态时刻仍各最多 8 张，单独删除可撤销；删除不会改写其他截图的编号或来源。

动态参考由插件送入，可添加视频或帧序列机位，已有机位和标记保留。最多 8 个机位，每个最多 600 帧。帧序列按来源清单排序，以指定帧率播放。视频由服务器用 FFmpeg 采样为参考帧。机位与动画 GLB 共用时间轴；点击左侧机位缩略图可保持当前时间，并按对应参考相机自动对齐。采样帧率不同时使用最接近当前时间的参考帧；较短机位在末尾保留最后一帧。未提供相机位姿的机位可手动对照。同一条提示可引用不同机位的标记，每个保留自己的截图和相机。多段 GLB 动画可选择具体动作。圈画时自动暂停并保留该时刻，最多保留 8 个时刻。参考顶部显示视频名与帧号，底部直接显示播放、逐帧和进度条；多动作 GLB 的动作选择显示在时间轴下方。修改时段直接写在提示中：输入 /，自动列出当前时间戳、当前参考帧、冻结场景截图、本轮标记与保留时刻，以及「本轮标记时段」和「整个片段」。双击时间轴当前时间或进度条浮标可引用当前时钟；浮标引起参考帧更新时，完成后才引用同一时刻，期间再改时间或机位则取消原引用；双击参考图上方帧号引用实际采样帧，双击截图卡片的时间引用该张截图保存的时刻。聚焦这些读数后也可按 Enter／空格；引用不切换视图；成功和等待时不弹提示，实际失败仍说明原因。参考帧更新中暂不可引用。可按机位、帧号、秒数或标记名搜索，用方向键选择、Enter 插入、Esc 关闭；菜单打开时 Ctrl / ⌘ Enter 只选择时间。场景时间和参考采样时间不同时会分别注明，时间按片段起点计算；提示中显示 🕒1 等图标编号，点击输入框内的时间卡片查看精确时间、机位与帧；发送时还原完整说明。已插入引用固定原来源，不随之后浏览变化；不跳转画面、暂停播放或改变标记。新反馈没有额外的默认范围。

左图悬停工具栏的「关键点」直接编辑当前原帧最新可用的人体证据；默认使用二维结果，无二维结果时显示最新三维投影。可拖动结果已声明的身体、脚、脸和手部关键点，区域筛选只显示已有区域。缺失点先选关节，再点击原图定位；「可见／遮挡／缺失」分别记录，「恢复原点」撤回单点修改。修改自动生成「关键点修改N」卡片并插入提示，同一来源帧的后续修改累加到同一份。右侧「物体与标记 → 关键点修改」只列本轮草稿，卡片显示源机位、帧和改动关节；支持 @ 引用、回看原帧、撤销／重做与移除整份。

关键点修改始终绑定原图、原坐标、改后坐标及来源，切换机位或时间不会挪到新图；保存成功后清理本轮修改，失败保留。旧手部草稿与人体引用仍兼容。参考叠层和新导出的骨架图只显示骨架与点，不画检测框或文字标签。来源、身份与二维观测／三维投影分类仍随引用保留；二维结果不自动确认跨机位身份或生成三维姿态。推理和重建由独立 capsule skill 执行，其 WholeBody 合并要求标准 133 点父结果。

显示「等待自动重试」时无需重复点击发送。「送达待核实」表示系统无法判断目标任务是否收到；先在目标任务中核对，确认未收到后再重试。事件投递失败后自动重试已停止；无活动订阅时反馈仍保存在工作台。检查插件连接，必要时让插件调用 workspace_get_feedback 按反馈 ID 读取图文证据。点击发送即可提交当前保留的截图和标记，旧截图无需再确认；场景更新不会中断投递，模型会收到原截图版本和投递时的当前版本。点击发送会保存当前截图、标记和提示，旧截图无需再确认；有插件订阅时会发出 MCP 事件。事件送达只表示插件接收端确认收到，不表示 Codex 已开始或完成执行。刷新会保留未发送的截图，不会把旧标记改写到新场景；需要重新圈画时可点「清除本图」，并可撤销恢复。服务器确认保存反馈后，本轮提示、全部标记、固定截图、保留时刻和物体/节点选择会自动清空，并回到实时 3D；已发送的图文证据可从聊天消息下方「查看图片与标记」重新打开，或在「侧栏 → 执行记录」查看事件。新结果到达时不会清除下一轮已开始的草稿。保存失败或结果未确认时，草稿保留；需要人工处理的反馈会显示在会话输入框上方，可在那里确认或重试。

在提示中输入 @ 可按名称、编号、ID 或类型搜索当前选中的物体或部件，以及本轮全部未发送标记和关键点修改；没有候选时会提示先选中物体或添加标记。跨机位、帧和截图的标记仍可搜索。选择箭头模式下双击左右图的可见标记，或双击标记列表条目，直接加入引用；列表单击稍后回看，键盘选择立即回看。方向键选择，Enter 插入，Esc 关闭，也可直接点击。菜单开启时 Ctrl / ⌘ Enter 选择引用，不发送。提示正文里的图标与上方来源标签都可单击打开附近的小详情浮层，鼠标离开引用和浮层后自动关闭；没有遮罩，不改变背景亮度，也不抢输入焦点；拖动选择文字不会打开详情。物品级引用显示 🧊，部件级引用显示 🧩；精确节点来源仍保留。图片通过输入框左下角「＋」添加；添加时固定原图、标记和来源，后续改变视角或帧不会改写它。本轮关键点修改也可用 @ 引用，卡片显示源帧和改动关节。

待确认操作显示在会话输入框上方，收起记录也可处理；收起整个会话时显示「! 待确认」，点击后直接定位到卡片。执行时仍显示转圈。右侧工具栏直接显示透明度拖条、地面方向和对齐。透明度 0% 隐藏叠图，向右拖动恢复；截图上的设置只影响该图。左拖旋转、右拖沿屏幕平移、滚轮缩放；实时 3D 双击物品或部件加入引用；物品清单和已选名称也可双击引用。单击仍选择，旋转与拖拽不会误引用；选中后按 F 聚焦。地面方向按场景记住；「对齐」恢复当前参考图的拍摄机位，无相机位姿时不可用。已有截图和标记保持原视角。侧栏中的「沉浸」让场景铺满应用，「对照」返回双栏；切换布局和日夜模式后侧栏保持打开；常用场景操作浮在右上角，最右侧箭头可收起整条工具栏，再点原位箭头展开；浏览器记住选择，对照模式始终显示工具栏。「参考」打开左侧浮窗。参考浮窗可拖动标题栏移动，拖四边或四角调整大小，标题旁的复位图标恢复默认位置和尺寸；位置与尺寸按浏览器保存，切回对照不影响双栏。聚焦标题栏后可用方向键移动，聚焦右下角缩放柄后可用方向键调大小。月亮／太阳切换日夜模式。
