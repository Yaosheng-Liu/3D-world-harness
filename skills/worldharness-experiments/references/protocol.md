# 本批实验协议

这批是第三版选定的10个DL3DV场景，当前只做主实验：10场景 × 3模型 × 3方法 = 90次独立运行；每次M0/M1/M2，最多270个建模检查点。可按“场景 × 模型”分配，每人负责该组合的三种方法，避免不同方法刚好由不同硬件承担。尚未完成的任务不能计为完成。

## 输入和三组区别

| 内容 | single_basic | single_tools | harness_tools |
|---|---|---|---|
| 原始训练/可见验证图与相机、相同简短任务 | 有 | 有 | 有 |
| 普通代码与Blender建模/预览 | 有 | 有 | 有 |
| 训练图DA3/TSDF观测初始化 | 无，只有格式示例 | 有 | 有 |
| SAM3、对象几何、深度诊断、多视角角点工具 | 禁止 | 自主按需调用 | 初始化自动调用＋建模可调用 |
| 独立计划Agent和初始化物体清单 | 无 | 无；工具请求可自行写 | 有 |
| 两次修订 | 同一建模会话自行检查 | 同一建模会话自行检查 | 独立审核反馈后建模会话修订 |
| Harness审核叠图/差异图/冻结审核材料 | 不提供，也不调用生成器 | 不提供，也不调用生成器 | 提供给审核Agent |

`single_basic`并不是禁止所有工具的纯文本模型：它仍能写Python、使用Blender和普通图像读取。`single_tools`拿到的观测几何与Harness同源，但没有独立计划或外部审核；避免把它偷偷变成另一个完整Harness。统一的编辑目标清单是评测任务声明，不是完整场景物体规划。

初始用户提示词逐字使用：

> 根据提供的多视角图像和相机信息，在 Blender 中重建场景。物体应可独立编辑，尽量匹配真实几何、布局、材质和外观，保存建模源码和场景工程。

单Agent修订提示词：

> 检查当前场景与参考图像，修正发现的问题并提交新版本。

三组共享格式/输出要求；单Agent的项目AGENTS.md保持简短。Harness计划、审核各有角色指令，因此“相同初始提示词”不等于三组全部上下文相同。详见生成后的`project/AGENTS.md`和`calls/*/prompt.txt`。

## 模型、轮次、外观

每个模型组的计划、建模、审核统一为同一模型：Astra/Sol用`ultra`，Luna用`xhigh`；不沿用旧Astra计划＋Sol审核的混合设置。已有相同干净纹理规则、输入、提示和轮次的单Agent结果可以保留，记录原协议与代码版本；混合角色Harness结果单列历史实验。不要仅因旧结果为ultra就排除。

Harness固定：计划、分割、对象初始化 → M0 → R1 → M1 → R2 → M2，收到“通过”也不提前终止。单Agent是M0 → M1 → M2，不增加外部审核。各组M0 3600秒，M1/M2无时间上限；计划900秒，审核不限时。工程工具的时间限制属于运行配置，本交接版默认不设专业工具硬期限，避免不同硬件因1小时分割超时而改变流程。异常或停止仍应保留日志。

本批只有`intrinsic`：允许物体自身干净纹理；禁止整图投影以及带其他物体/光影的照片贴图；显式灯光和受光材质。字段检查不等于满足纹理要求，还需看源码、纹理和编辑图。物理不在本批任务内。

## 数据与评测隔离

- 输入压缩包包含3622帧原图，不是预先提供给Agent的全部可见输入。
- `prepare.py`按原序列生成48训练＋6可见验证，以及12个私有测试中心及±6支持窗口；这些窗口排除于训练与可见验证。所有方法用相同划分，相机/畸变审计写入记录。
- DA3仅处理48训练帧，分辨率756，模型DA3NESTED-GIANT-LARGE；TSDF是中性的观测几何，没有照片图集或补全。两工具组复用同一份缓存。
- 同一“场景 × 模型”的三方法应共享一次预处理。多人跨机器重复初始化需比较深度/几何哈希；不相同就记录环境差异，不能宣称逐字节相同。需要严格一致时由协调者另发冻结的训练观测缓存及来源，不发旧建模结果。
- 私有测试图、稀疏参考和测试指标不进Agent项目，也不作为返修意见。workspace-write沙盒不是读取隔离安全边界，不能把工程路径约定称为完全防泄漏机制。

## 指标和成本

1. **外观**：12个测试相机，宽640，Cycles32采样，OIDN2.5.1，Standard曝光0。报告PSNR↑、SSIM↑、AlexNet LPIPS↓，保存逐视角图。全图均值可能掩盖局部摆放错误，不把它当完整空间正确性。
2. **空间**：从私有支持窗口做三视角SIFT三角化，独立于DA3；属于稀疏伪参考，不是扫描真值。射线首次命中的相对距离误差 `|t-d|/d` 与参考点到模型表面的最近距离 `dist/d`，均截断到1，缺失计1；同时报告射线覆盖率、1/2/5/10%阈值准确率。没有逐方法ICP/尺度拟合。后一指标单向且不感知语义，不能单独判定床的朝向正确或物体完整。
3. **编辑**：每场景5个预先声明目标，平移、旋转、缩放、隐藏、材质修改；机械变换和保存重开检查、非目标对象变化率。另看逐物体分离、所属部件、残留、支撑关系与暴露背景的截图。机械通过率100%不等于语义可编辑性100%。新增场景目标以原始输入描述，找不到填null，不能换成更容易的物体。
4. **成本/可靠性**：按角色记录输入、缓存输入、输出、推理输出、总Token、墙钟时间、失败阶段/原因、工具调用耗时、预处理成本、GPU/CPU/软件版本。总Token为输入＋输出；缓存输入是输入子集，推理输出是输出子集，不重复相加。resume计数是累计值，应使用仓库聚合器，不把M0/M1/M2累计快照再相加。失败用量也要保留。

先分别报告M0/M1/M2与完成率，再对共同完成样本比较方法。不要只报告成功样本均值而隐藏失败；场景作为主要汇总单位，多视角不是独立场景。各模型/方法的单次运行是探索性结果，不提供重复采样方差保证。当前不做推理程度、模块或纹理消融。
