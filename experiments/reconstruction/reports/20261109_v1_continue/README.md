# 统一续跑实验最终自动指标

24/24组完成三次建模，72/72个版本完成自动评测，当前无未处理的运行错误。语义编辑核验待完成，以下不宣称场景已达到真实还原质量。

本批是三个开发场景、每条件一次运行的探索性续跑。18个M0复用v1，继承首版与补齐首版的历史预算不同；单Agent曾暴露外部审核材料的旧返修被隔离，重新从干净M0会话续接。部分提交/报告规则和离线GLB预算在执行期间修订，原始失败、恢复原因及消耗均保留，submission_policy逐试验标记恢复策略。该标签不表示旧M0重新生成。完整Harness同时改变计划组织、自动初始化和独立审核，当前对照不能单独归因某一组件。

每版用12个私有测试视角、640像素宽、32次Cycles采样和相同OIDN计算外观指标，不作曝光/颜色拟合。几何采用留出图像三视角三角化的稀疏参考，误差按参考射线长度归一化；截断为1，缺失记1，逐帧等权平均，不作配准或尺度拟合。这不是完整扫描真值。

编辑率仅为5个声明目标×5种操作的机械检查；语义归属和拆分完整性尚待独立视觉核验。没有进行物理真实性评测。Token按线程累计快照去重后合并角色，缓存输入/推理输出为子项；调用累计耗时不同于并行墙钟时间。隔离旧返修、v2诊断及共享初始化成本分别保留，不能把本表直接解释为全部项目费用。
